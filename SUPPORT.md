# Support and contact routes

Choose the route that matches the information involved.

| Need | Route |
|---|---|
| Discuss a customer evaluation, site context or operating constraint | [Book a private evaluation call](https://calendar.app.google/jYG6MXGrGHncnjAUA) |
| Report a reproducible non-sensitive defect | [Open a defect report](https://github.com/charifmahmoudi/mobile-ot-security-assessment/issues/new?template=bug.md) |
| Propose an evidence-backed research correction | [Open a research claim](https://github.com/charifmahmoudi/mobile-ot-security-assessment/issues/new?template=research.md) |
| Propose an architecture, UX, data or safety decision | [Open a design proposal](https://github.com/charifmahmoudi/mobile-ot-security-assessment/issues/new?template=design.md) |
| Report a vulnerability | Follow the private process in [SECURITY.md](SECURITY.md) |
| Understand current capability | Read [IMPLEMENTATION.md](IMPLEMENTATION.md) |

Do not publish customer names, site names, contacts, addresses, credentials, network identifiers, packet data or sensitive operational details in a public issue.

Atlas is currently a research prototype. There is no production support commitment, service-level agreement or supported production release.
