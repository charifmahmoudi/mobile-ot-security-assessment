# Contributing

This project is in research and design. Contributions should improve evidence, safety, requirements or architecture before adding assessment code.

1. Open an issue describing the claim, source or decision.
2. Use a focused branch and conventional commit.
3. Mark facts as Verified, Corroborated, Inferred or Unknown.
4. Cite primary sources near the claim and update the source register.
5. Never publish credentials, packet payloads, customer data, personal lead lists or guessed emails.
6. Any packet-producing design must specify authorization, risk class, exact request, rate/retry/timeout budgets, stop behavior and golden-packet tests.
7. Submit a pull request using the template.

Code contributions later require tests, SBOM/dependency updates, license compatibility and security review.
