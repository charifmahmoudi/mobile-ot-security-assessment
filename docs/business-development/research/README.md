# Business-development research archive

This directory supports the operating sales system with public-source evidence. It does not contain pipeline stage, contact status, next actions or sales forecasts.

## Canonical research assets

- [Account research notes](ACCOUNT-RESEARCH-NOTES.md) — one concise public-signal and problem-hypothesis record per target organisation
- [Ecosystem and transition context](ECOSYSTEM.md) — current operators, predecessor boundaries, delivery participants and financing context
- [Public profile lead pool](PUBLIC-PROFILE-LEADS.csv) — broader public-profile research; a person moves into `../contacts.csv` only when attached to an active account plan
- [Web source register](WEB-SOURCE-REGISTER.csv) — source IDs, dates, grades and supported claims
- [Public employee-event ledger](EMPLOYEE-EVENT-LEDGER.csv) — raw public professional/event observations used to verify contact relevance

Commercial state is maintained only in [`../pipeline.csv`](../pipeline.csv). Active people and relationship state are maintained only in [`../contacts.csv`](../contacts.csv).

## Evidence grades

| Grade | Meaning | Permitted use |
|---|---|---|
| A | Government, operator, corporate or development-finance primary source | Organisation status, mandate, official figures and announced projects |
| B | Established reporting attributable to official or company statements | Corroborated project and investment context |
| C | Public-tender mirror referring to an official procurement portal | Lead only; verify the official notice before action |
| D | Contextual analysis | Research question only |

A source supports only the claim recorded in its row. Public information does not establish demand, buying authority, budget, installed technology, vulnerability or permission to access a system.
