# Morocco water-sector accounts

_Research baseline: **1 September 2026**._

This directory is the customer and account intelligence layer for Atlas OT Scout. It covers actual Moroccan organisations with drinking-water, wastewater, desalination, reuse, pumping, storage, distribution or project-handover responsibilities.

The current universe contains **14 strategic accounts**: ONEE Water Branch, all 12 regional multiservice companies, and OCP Green Water. Legacy operators and delivery partners are classified separately so historical mentions are not mistaken for current buying authority.

## Evidence rules

- Prefer official operator, government and development-finance sources.
- Use established press for attributable project and board statements.
- Treat tender aggregators as mirrors; verify the official notice before outreach or commercial action.
- Separate verified facts from Atlas's OT-relevant hypotheses.
- Never infer installed products, vulnerabilities, credentials, topology or budget availability.
- Recheck corporate status, contract perimeter, tender status and role ownership on the day of outreach.
- Field access requires written authorization, an exact scope, named evidence custodians and a documented stop condition.
